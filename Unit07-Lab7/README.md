# Lab 7: Reinforcement Learning, Robotics & AI Ethics

## 1. Aim / Problem Statement
To implement autonomous decision-making agents and algorithmic fairness auditing across 3 standalone Python programs:
1. **Q-Learning Grid World (`1_QLearning_GridWorld.py`):** Train a reinforcement learning agent using the Bellman Equation and $\epsilon$-greedy exploration.
2. **Robot Obstacle Navigation (`2_RobotObstacleNavigation.py`):** Compute a collision-free shortest path on a 2D warehouse occupancy grid.
3. **AI Fairness & Bias Audit (`3_AI_FairnessBiasAudit.py`):** Evaluate automated decision outcomes across demographic groups using the 80% Disparate Impact Rule.

## 2. How to Run
bash
python 1_QLearning_GridWorld.py
python 2_RobotObstacleNavigation.py
python 3_AI_FairnessBiasAudit.py
