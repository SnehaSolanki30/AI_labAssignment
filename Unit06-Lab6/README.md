# Lab 6: Natural Language Processing (NLP) & Computer Vision

## 1. Aim / Problem Statement
To process unstructured text and 2D image matrices across 3 standalone Python programs:
1. **NLP Text Preprocessing (`1_NLP_TextPreprocessing.py`):** Perform lowercasing, punctuation removal, tokenization, stop-word filtering, and suffix stemming.
2. **Sentiment Analysis (`2_NaiveBayes_SentimentAnalysis.py`):** Classify text reviews into Positive or Negative sentiment using a Multinomial Naive Bayes classifier.
3. **Computer Vision Edge Detection (`3_ComputerVision_EdgeDetection.py`):** Apply 2D Sobel convolution kernels ($G_x, G_y$) to extract object edges from grayscale pixel matrices.

## 2. How to Run
bash
python 1_NLP_TextPreprocessing.py
python 2_NaiveBayes_SentimentAnalysis.py
python 3_ComputerVision_EdgeDetection.py
