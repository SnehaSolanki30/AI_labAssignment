# Lab 4: Probabilistic Reasoning & Knowledge Representation

## 1. Aim / Problem Statement
To model uncertainty and structured domain knowledge in AI systems across 4 standalone Python programs:
1. **Bayes' Theorem Inference (`1_BayesTheoremInference.py`):** Compute posterior disease probabilities given diagnostic test sensitivity and false-positive rates.
2. **Bayesian Belief Network (`2_BayesianNetwork.py`):** Perform joint and conditional probability inference over a directed acyclic graph (Alarm System).
3. **Hidden Markov Model (`3_HiddenMarkovModel.py`):** Infer the most likely sequence of hidden states from observations using the Viterbi Algorithm.
4. **Knowledge Representation (`4_KnowledgeRepresentation.py`):** Structure semantic relationships and entity-attribute facts for automated reasoning.

## 2. How to Run
bash
python 1_BayesTheoremInference.py
python 2_BayesianNetwork.py
python 3_HiddenMarkovModel.py
python 4_KnowledgeRepresentation.py
