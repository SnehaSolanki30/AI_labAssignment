# Lab 3: Logical Reasoning, Constraint Satisfaction & Game Playing

## 1. Aim / Problem Statement
To implement symbolic reasoning, constraint satisfaction, adversarial game search, and data preprocessing pipelines across 4 standalone Python programs:
1. **Propositional Logic Inference (`1_LogicalInference.py`):** Derive new logical conclusions from a Knowledge Base of facts and `IF-THEN` rules using Forward Chaining.
2. **Constraint Satisfaction Problem (`2_CSP_NQueens.py`):** Solve the $N$-Queens problem on an $N \times N$ chessboard using Backtracking.
3. **Adversarial Search (`3_Minimax_AlphaBeta.py`):** Compute optimal Tic-Tac-Toe moves using Minimax with Alpha-Beta Pruning.
4. **Data Preprocessing (`4_DataPreprocessing.py`):** Clean, encode, and scale structured datasets for downstream AI modeling.

## 2. How to Run
bash
python 1_LogicalInference.py
python 2_CSP_NQueens.py
python 3_Minimax_AlphaBeta.py
python 4_DataPreprocessing.py
